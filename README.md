# 🏆 Fortnite Hunt - Escenario 2D interactivo

## 📍 Contexto
[cite_start]Este proyecto es una aplicación web interactiva desarrollada para la materia de Graficación en el Instituto Tecnológico de Pachuca[cite: 2, 3]. [cite_start]Se basa en la implementación de gráficos 2D dinámicos utilizando estándares web modernos[cite: 6].

## 🎯 Objetivo
[cite_start]El objetivo es cumplir con las reglas de negocio establecidas para la evaluación de las Unidades III y IV [cite: 9][cite_start], creando un sistema que gestione 25 objetos (Llamas de suministros) con movimientos aleatorios, circulares y diagonales[cite: 11, 14]. [cite_start]El sistema incluye detección de colisiones con rebote y animaciones de impacto[cite: 15].

## 💡 Justificación
[cite_start]Se eligió la temática de Fortnite para aplicar conceptos de graficación como el mapeo de texturas en objetos móviles, la gestión de audio sincronizado y la personalización de la interfaz de usuario (UI) mediante cursores y fondos temáticos[cite: 16, 19, 20]. [cite_start]La lógica del juego demuestra el control de estados en un Game Loop y el manejo de eventos del mouse[cite: 18].

## 🕹️ Operación y Conclusiones
**Operación:**
- [cite_start]El usuario debe hacer clic en las llamas que se mueven por el mapa para "recolectar" botín[cite: 18, 26].
- [cite_start]Cada acierto se registra en un contador visual integrado con Bootstrap[cite: 23, 25].
- [cite_start]Los objetos rebotan entre sí y con los bordes del canvas, manteniendo siempre la población de 25 elementos en pantalla[cite: 11, 18].

**Conclusiones:**
[cite_start]Logramos integrar una estética de videojuego comercial en una herramienta académica, resolviendo problemas complejos de física de partículas para las colisiones[cite: 15]. [cite_start]El uso de Git y GitHub permitió mantener un control de versiones estricto, asegurando que cada mejora en la lógica de movimiento circular y lineal fuera documentada correctamente[cite: 35, 36, 40].
